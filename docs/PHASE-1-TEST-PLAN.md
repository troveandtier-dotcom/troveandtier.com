# Phase 1 test plan

Run locally after installing dependencies:
1. `npm install`
2. `npm run check`
3. `npm run build`
4. `npm run dev -- --host 127.0.0.1`

Manual browser checks:
- Desktop navigation, search route and country selector.
- Mobile menu open/close and keyboard access.
- Every room/category route and all three journal articles.
- About, how-we-choose, affiliate disclosure, contact, privacy and terms.
- Search filters and zero-result state.
- 404 page for unknown routes.
- Check keyboard focus, reduced motion, heading hierarchy, contrast and link labels.
- Check at 360px, 390px, 768px, 1024px and desktop widths.
- Confirm there are no fake products, prices, affiliate links, newsletter collection or testimonials.

Not yet executed. Record actual outcomes and Lighthouse scores before release.
