# Trove & Tier

**Thoughtful finds. Better living.**

A curated home & living editorial publication for readers in the US, UK and Canada.

## Project status

Phase 1 — public-site foundation and approved homepage implementation. No production deployment has been authorized.

## Stack

- Astro + TypeScript
- Cloudflare Workers Static Assets (planned production host)
- Supabase (planned private editorial studio; not yet integrated)

## Development

```sh
npm install
npm run dev
npm run check
npm run build
```

See `docs/BUILD-STATUS.md` for verified progress and next steps. The sample content is illustrative only and must not be represented as tested products, real prices, or affiliate recommendations.
